클릭부터 주문까지, 끊긴 데이터를 하나의 퍼널로 연결했습니다

한 줄 요약

SA·DA·APP 캠페인을 운영하며, GA4와 AppsFlyer를 연결해 설치 이후 재유입·주문까지 단계별 기여를 비교했습니다. 예산 판단의 최종 기준을 클릭이 아니라 실제 주문 기여로 바꿨습니다.

기간
2023.09 – 2024.02
역할
매체 운영 · 퍼널 분석 · 예산 조정안 · 컨셉 메시지 제안
기여 범위
20%

근거 형태 — 내부 Daily ID · GA4 · AppsFlyer · 소재 기획 요청서

  • 운영 범위 SA·DA·APP

웹 광고와 앱 설치·재유입·구매 데이터가 서로 다른 도구에 나뉘어 있어, 클릭 효율만으로는 큰 예산이 실제로 무엇에 기여했는지 판단하기 어려웠습니다. 흩어진 지표를 한 퍼널에 놓고 단계별로 비교했습니다.

업종
홈퍼니싱 · 커머스
담당 채널
네이버 SA · DA · 앱 캠페인 · GA4 · AppsFlyer

01

실행

  • SA·DA·APP 캠페인 통합 운영
  • 브랜드 세일 컨셉 메시지 제안 — 행사·브랜드·대표성으로 강조축을 나누고 안마다 근거를 붙임
  • 네이버 SA 키워드 · BSA 브랜드 · 플러스친구 세 계정의 인수인계 문서 작성
  • GA4·AppsFlyer 상세 데이터 연결
  • 퍼널 단계별 이탈과 매체 기여를 정기적으로 점검

02

나의 역할

매체 운영, GA4·AppsFlyer 퍼널 분석, 리포팅과 예산 조정안 도출을 담당했습니다.

기여 범위20%

03

출처

PlayD 한샘 Daily ID Report 최종 보정본, GA4·AppsFlyer 운영 데이터 기준. 집행 규모는 최대 월 기준이며, 웹·앱 지표는 대표 캠페인 구간 누적 기준으로 서로 다른 기간을 집계한 수치입니다. 이 사례는 역할 분리(직접/함께/하지 않은 것) 문서를 보유하지 않아 해당 항목을 비워 두었습니다. 없는 근거를 만들지 않기 위해서이고, 제 기여 범위는 인터뷰에서 구술로 설명드립니다.

04

배운 것

설치량이 많은 매체가 주문을 만드는 매체와 달랐습니다. 대형 예산일수록 마지막 기준을 주문 기여로 두는 편이 안전했습니다.

05

실행 화면과 증빙

공개 자료는 실제 운영·집행 맥락을 확인할 수 있는 범위만 선별했으며, 제작물과 개인 기여 범위는 캡션에서 구분했습니다.
